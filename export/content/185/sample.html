Capacity Manager Reports 
 
 All the reports here pertain to APTARE StorageConsole's Capacity Manager module. Some the reports contained in this library may require some initial setup in order to work. For example, any report containing attributes such as "Site" will require you to create a user defined attribute called "Site" for your storage arrays. Then assign the appropriate values to that array attribute i.e. New York, Dallas, London, Paris, etc..
