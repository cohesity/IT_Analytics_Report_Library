# IT Analytics Report Library

A collection of unique report templates created by the Veritas/Cohesity IT Analytics
community, available for all customers and partners. Reports can be downloaded and
used as-is or customized to suit your own environment.

Browse by **[Category]({{ '/categories/' | relative_url }})** or
**[Product]({{ '/products/' | relative_url }})** in the sidebar, or use the search
box above. Each report page has a **Download Template** button (the `.rtd` file to
import into your portal) and a **View Sample Output** link showing what the report
looks like when run.

Examples of reports here are provided as-is and are **not officially supported**.
